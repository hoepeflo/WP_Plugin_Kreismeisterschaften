Hier werden die Quelldokumente für das Konvertierungsskript (Meilenstein 3) abgelegt.
Sie gehören nicht in das ausgelieferte Plugin.

| Datei | Inhalt |
|---|---|
| `01A1_Disziplinenplan_2026-Aktuell_17_02.xlsx` | NSSV-Disziplinplan 2026 (Regeln Disziplin × Klasse) |
| `01A1_Disziplinenplan_2026-Aktuell_17-02.pdf` | dasselbe als PDF zur visuellen Kontrolle |
| `01A2_Jahrgangsklassen_nach_DSB_.pdf` | Jahrgangstabellen |
| `06A1_Disziplinenplan_Bogen_2026_Stand_12_03_2026.pdf` | Bogen-Disziplinplan |
| `david21_muster.png` | Aufbau des DAVID21-Imports |

`bogen-2026-vorlage.csv` ist die leere Vorlage für die Bogen-Regeln (siehe `tools/README.md`);
die ausgefüllte Datei als `bogen-2026.csv` daneben ablegen.
